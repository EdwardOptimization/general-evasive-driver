## Interpretation

Supported:

```text
1. Capability-step events produce broad recurrent-state sensitivity.
2. Reset-hidden rows are source-diverse and useful as diagnostic seeds.
3. The current wrong-history injection is too weak or too compatible.
4. The next step should change intervention design, not lower thresholds.
```

Falsified:

```text
1. M991 is source-positive for wrong-history self-identification.
2. More same-style cross-fault mining is the highest-leverage next step.
3. Reset-only rows can be treated as accepted wrong-history proof.
4. The branch is ready for training or PPO.
```

## Route Decision

Decision:

```text
route_to_sequence_level_action_response_mismatch_design
```

Rationale:

```text
The actor reacts strongly to reset-hidden, but not to current wrong histories.
So the next intervention should not be another static hidden swap. It should
construct a stronger incompatible command-response history over a short
sequence, then test whether that sequence-level belief mismatch changes the
closed-loop outcome.
```

M993 should design a no-training sequence-intervention probe using M991
reset-only rows as candidate sources.

Candidate interventions:

```text
wrong_history_sequence:
  inject a hidden state generated by rolling a paired incompatible fault for K
  steps before the emergency snapshot;

action_response_mismatch_sequence:
  replay commands from one capability family while feeding response evidence
  from another family;

delayed_history_sequence:
  feed a stale hidden/response trace from before the capability step;

zero_command_history_sequence:
  remove recent command evidence while keeping ego response;

reset_then_warm_history:
  reset hidden, then run K observed command-response steps before the decision.
```

Acceptance should require terminal/outcome relevance:

```text
normal history retained;
sequence intervention lowers margin or success;
wrong-history sequence action differs for the right reason;
source diversity across seeds and fault pairs;
no actor-input contract violation.
```

## Blocked Routes

Do not:

```text
train from M991;
run PPO;
promote a checkpoint;
export reset-only rows as wrong-history accepted rows;
continue same-style cross-fault mining without a new intervention;
claim true per-wheel/asymmetric fault support.
```
