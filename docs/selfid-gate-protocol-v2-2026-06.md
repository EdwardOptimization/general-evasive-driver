## 1. 为什么重写（P4 缺陷回顾）

对抗评审（`experiments/feasibility_audit/voi_commitment_adversarial_audit.json`）发现：
**探测脉冲结束后的任意单帧观测都能线性回出 μ**（评审实测探测后单帧泄漏 R² = 0.975；
本最终规格全保真度复测：探测窗末帧单帧 R² = **0.9409**）。因此旧 gate 把 wrong-history /
hidden-swap 比较锚定在探测后帧上时，无历史的策略也能从"当前帧"重新推出 μ ——
历史依赖测试形同虚设。同时单一行为签名可被沉默梯子（P2 族）伪造。

## 2. 测量锚点规则（hidden-swap / wrong-history）

- **规则**：所有 hidden-swap / wrong-history 比较的锚点帧序号必须 **≤ 首个探测脉冲起点
  （step 12，Task-B 控制器 PULSES[0]）**；标准锚点 = **step 11**（最后一个保证无脉冲的帧）。
- **实测依据**（最终规格，160 集/条件，连续 μ∈[0.254, 1.147]）：
  - 脉冲前锚点帧单帧→μ 线性探针 R² = **−0.0382**（≤ 0.1 ✅，无泄漏）；
  - 探测后末帧单帧→μ R² = **0.9409**（强泄漏，禁止做锚点）；
  - 对照：评审版（reveal 10/jitter 2.0 规格）探测后单帧 R² = 0.975，同一结论。
- 历史通道本身可推断性（active probe 整窗历史→μ）：R² = **0.9999**；
  no-probe 对照整窗 R² = **−3.085**（信息确实由探测脉冲注入，而非被动可读）。

## 3. 三签名合取（任何单项均可被伪造，必须同时成立）

| 签名 | 判据 | 本轮实测支撑 |
|---|---|---|
| S1 入弯速度秩相关 | 面板上 Spearman(reveal 穿越速度, μ) ≥ **0.8**，且必须**高于先验白送对照臂**的同指标 | 沉默梯子可借 d(μ)+ε 残余相关性部分伪造 S1（P2 测得最佳梯子 validated 0.3611 的成功率仍非零），故 S1 单独不裁定 |
| S2 准备段动作能量 | prep 段 mean Σa² **高于无探测基线**（同族无脉冲计划的 prep_action_sq_mean） | probe 对 no-probe 的 R² 对比 0.9999 vs −3.085 证明能量差对应真实信息注入 |
| S3 面板成功率 | ≥ **gate-3 bar = best_fixed_validated + 0.5 × VoI_validated = 0.5278 + 0.5×0.3889 = 0.7223** | best_fixed = cem_robust（CEM 鲁棒对抗计划，validated 0.5278）；VoI(±0.2 先验) validated 0.3889 ≥ 0.2 目标 |

**合取要求**：S1 ∧ S2 ∧ S3 同时成立才算行为级自我识别签名；
任何单项都存在已实测的伪造路径（S1—梯子；S2—无信息抖动；S3—bin 对冲）。

## 4. 先验白送对照臂（强制）

任何 gate 运行必须包含一个对照臂：策略把 ±0.2 的 μ bin 作为免费观测常量获得。
该臂的脚本化天花板 = bin-aware 最佳固定计划 **cem_robust（validated 0.5278）**。
一个只追平该天花板的"自我识别"策略学到的是 bin 对冲而不是识别；
必须同时在 S1 上显著高于该对照臂（对照臂 S1 期望 ≈ 0，固定入弯速度）。

## 5. Gate 自检（每次 gate 运行前必跑）

- **自检判据**：承诺时刻参照帧（= 锚点帧，step ≤ 12 之前的单帧）→ μ 的线性探针
  R² ≤ **0.1**。本轮实测 −0.0382 ✅。
- 同时报告探测后末帧 R²（本轮 0.9409）作为"锚点不可后移"的持续证据；
  若某次改版使锚点帧 R² > 0.1，gate 失效，必须回查任务/观测布局再运行。
- G1' 中该自检有行为级镜像：当前帧臂若也学出 μ→速度映射（中位数 Spearman > 0.4），
  即判 gate 自检失败、回查 P4（见 G1' 预注册）。

## 6. 验证种子要求

- 种子流基（最终规格）：**20260615**；
  锚面板 `20260615*10 + level*1000 + k`（k 0..15；key-cell 两不相交组 k 100../200..）；
  bin `20260615*10 + offset(50000/90000) + 17*point + 1000*k`（验证相 +100000）；
  probe `20260615*100 + mode*10000 + episode`；
  jitter `U(−J,J) ← default_rng([20260615, 777, rollout_seed])`。
- **选择/验证分离**：所有计划选择（best fixed / ladder / oracle / CEM）在 sel 种子上做，
  报告值一律取不相交 val 种子（gate-3 bar 的 0.5278 与 0.3889 均为 validated 值）。
- key-cell 一致性：gate 相关单元（oracle、best_fixed）需两组不相交种子 |ΔA−B| ≤ 0.25
  （本轮 gate 相关单元全部一致 ✅）。
- 任何后续 gate / 训练运行必须使用与上述全部流不相交的种子流
  （G1' 使用 20260616 基，demo +300000 / eval +600000）。
