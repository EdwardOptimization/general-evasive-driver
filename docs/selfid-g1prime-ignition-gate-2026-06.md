## 2. 预注册判据（运行前写定，未事后改动）

G1' PASS =（a）历史臂 8-seed 入弯速度-μ Spearman **中位数 ≥ 0.8** ∧（b）当前帧臂**中位数 ≤ 0.4**
∧（c）两臂逐 seed 差的配对 bootstrap（10 000 次重采样）**95% CI 不含 0**。
有效性前置条件：保留示教 ≥60%；每 run reveal 覆盖率 ≥50% 方为有效 run；每臂有效 run ≥6。
FAIL 语义（预注册）：历史臂 <0.8 → 教师/任务设计回炉；两臂都学得出 → 当前帧泄漏、gate 自检失败、回查 P4；

## 5. 关键诊断（实测 + 推断，分开标注）

1. **（实测）教师可行、映射可学的上界存在**：教师闭环 ρ=0.9955 / 成功率 0.906。
2. **（实测）两臂闭环成功率坍塌**（~0.10 vs 教师 0.91），而训练损失 ~0.009：
   纯行为克隆的复合误差/分布漂移，4-epoch 烟雾测试成功率反而更高（0.92），过训练加剧脆性。
3. **（实测）当前帧臂稳定 μ-耦合（|ρ|≈0.7，符号为负）**：预注册判据是单边的（≤0.4），
   字面满足；但幅值表明**当前帧 + 自体速度寄存器足以承载 μ**——与最终规格 P4 帧级测量一致
   （探测后单帧 R²=0.9409；评审版 0.9745；无探测时仅 0.0149）。刹车脉冲把 μ 写进持续
   物理状态（速度），任何后续帧都可读出。
4. **（实测）hidden-reset 不退化**：即便历史臂，承载信息的主要也是物理状态而非 GRU 记忆。
5. **（推断）结论**：在现行任务族上，"历史臂 vs 当前帧臂"的策略类对比无法分离
   "内部记忆"与"具身物理记忆"；G1'' 必须先做 P4 级任务修复再重测。

## 6. 回炉路由（FAIL 路由，预注册语义 + 具体化）

按预注册：**教师/示教设计回炉，不升级 RL**。具体修复项（按依赖顺序，均可预注册量化验收）：

1. **P4 物理寄存器修复（任务级，先行）**：把全刹车探测脉冲改为**转向脉冲**（横向响应瞬态、
   不改变纵向速度），μ-印记只存在于 yaw/ay 响应历史中。
   验收（运行前预注册）：探测后单帧→μ R² ≤ 0.1 **且** 历史窗→μ R² ≥ 0.9（复用
   `probe_and_leak` 机器）。当前刹车脉冲的对照数字：单帧 0.9409 / 历史 0.9999。
2. **示教协议修复（闭环坍塌）**：示教生成时注入动作噪声（教师动作 + 小扰动，状态覆盖加宽）
   或 1 轮 DAgger 式重标注；训练加 held-out 集 epoch 选择（防过训练脆化；实测 4 epochs
   成功率 0.92 → 25 epochs 0.09 的反向剂量效应）。
   验收：两臂闭环成功率中位数 ≥ 0.5×教师成功率，否则不进入签名裁定。
3. **判据修复（G1'' 预注册）**：当前帧臂判据由单边 ρ ≤ 0.4 改为**双边 |ρ| ≤ 0.4**
   （本轮 −0.698 暴露单边判据可被符号反转穿过）；其余判据与有效性前置条件不变。
4. 完成 1–3 后重跑 G1''；若历史臂仍 <0.8 → 任务族回到设计层（VoI 虽为正，
   但映射的监督可学性不足，m1087 阶段链冻结）；若 G1'' PASS → 再写 m1087 全预算
   RL 训练预注册（gate 协议 v2 + G1'' 实测 bar）。

**附带风险登记（与本闸门并行）**：最终规格残差 P1 FAIL（θ4 γ=0.743 < 0.9，重定价网格无解）、
KE FAIL（分数格 0.268 ≥ 0.15）——进入 G1''/m1087 预注册时必须作为已知风险显式引用。
